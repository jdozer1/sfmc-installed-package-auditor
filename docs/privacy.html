Summary

SFMC Installed Package Auditor operates against the Salesforce Marketing Cloud account the user is already signed into. The extension does not operate a developer-controlled backend service and does not send SFMC package inventory, Data Extension content, authentication data, or browsing data to the developer, advertising networks, analytics providers, or data brokers.

The extension does not collect or store user-entered credentials, passwords, or OAuth client secrets. It uses the user’s existing authenticated Salesforce Marketing Cloud browser session only to perform the extension’s disclosed functionality. Temporary SFMC authentication/session data is used only in memory and is not persisted or included in exported diagnostic output.

Data the extension handles

  • Current SFMC page URL: used transiently to determine the SFMC tenant/stack needed to call the correct first-party SFMC endpoints.
  • SFMC authentication/session information: existing authenticated session cookies and temporary SFMC tokens are used in memory to make first-party SFMC requests. Tokens are not stored and are excluded from debug output.
  • SFMC account metadata: the extension requests the current SFMC user context to determine the active Business Unit/MID. The underlying SFMC response may contain account-identifying information such as user name, username, and email address; that response body is not written to the staging Data Extension and is not included in exported debug output.
  • Installed Package metadata: package ID, name, description, install metadata, Client ID, activity metadata, and secret-expiration metadata exposed by SFMC.
  • Data Extension metadata: Data Extension existence, schema, and folder/category metadata required to validate or create the staging DE.
  • Local diagnostics: users can explicitly copy or download sanitized diagnostic JSON. These files remain under the user's control unless the user chooses to share them for support.

How data is used

Data is used only to provide the extension's single purpose: inventorying SFMC Installed Packages, validating or creating the required SFMC staging Data Extension, and staging package metadata for package/API-IP and client-secret expiration auditing.

Data sharing and transfer

The extension communicates only with first-party Salesforce Marketing Cloud exacttarget.com endpoints required for the user-facing feature. It does not transfer user data to the developer or unrelated third parties. Data written by the extension is written into the user's own Salesforce Marketing Cloud tenant after explicit confirmation.

Storage and retention

The extension does not maintain a developer-controlled database and does not persist SFMC authentication tokens. Installed Package metadata written to the staging Data Extension remains in the user's SFMC account and is governed by that organization's Salesforce Marketing Cloud configuration and retention practices. Locally downloaded diagnostic files are retained only as long as the user keeps them.

Security

Network communications use HTTPS. Actual OAuth client-secret values are not collected or stored. Authentication tokens are used only in memory and are redacted from debug output.

Limited Use

Use of user data is limited to providing and improving the extension's disclosed single purpose. User data is not used for advertising, profiling, sale, or unrelated purposes. Humans do not access extension-handled data unless a user intentionally shares specific diagnostic information for support, or access is otherwise required by law or necessary for security.

Changes and support

Material changes to these data practices will be reflected in this policy and, where required, in the Chrome Web Store listing or extension UI. For support, use the support page linked from the Chrome Web Store listing.
