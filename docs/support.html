Before requesting support

  • Confirm you are signed into Salesforce Marketing Cloud in the active Chrome tab.
  • Open the extension and use Refresh.
  • Expand Diagnostics / debug output.
  • Download the sanitized debug JSON if the workflow fails.

What to include

Include the extension version, the step that failed, the HTTP status shown in diagnostics, and the sanitized debug JSON if appropriate. Review the file before sharing it because Installed Package names and metadata may be tenant-specific.

Important

Do not send Salesforce passwords, OAuth client-secret values, or manually copied authentication tokens in a support request.

Support channel

Use the Chrome Web Store support channel for the extension, or the issue/support link configured by the publisher on the store listing.
